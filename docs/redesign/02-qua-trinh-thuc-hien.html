5. Sự cố gặp phải

5.1 “Hình ảnh đang bị stretch”

Quan sát: toàn trang tràn hết chiều ngang, khung ảnh 16:9 bị kéo rất rộng.

Nguyên nhân: dev server chưa biên dịch lớp .site-container mới trong globals.css (CSS phục vụ ra thiếu lớp này), nên mọi trang mất giới hạn chiều rộng.

Xử lý: sửa lại globals.css để buộc biên dịch lại và xác nhận CSS đã có lớp. Ngoài ra khối chủ đề chỉ có một bài được đổi sang bố cục ảnh trái, chữ phải để ảnh không bị phóng to hết chiều ngang. Kiểm tra bằng ảnh thử dọc 400×600: ảnh được cắt đúng 16:9, không méo. Ảnh và bài thử đã xóa.

5.2 “Recoverable Error” ở trang quản trị

Quan sát: console báo “Hydration failed because the server rendered HTML didn't match the client”.

Nguyên nhân: bundle server của route /admin trong cache Turbopack vẫn render navbar cũ (max-w-[820px]…) trong khi code client đã là bản mới. Các trang khác không bị. Đây là cache dev cũ, không phải lỗi mã nguồn.

Xử lý: dừng dev server cũ và chạy lại npm run dev. Sau đó /admin trả navbar mới và không còn lỗi hydration. Việc xóa thư mục .next bị hook của project chặn nên không thực hiện; restart là đủ.
