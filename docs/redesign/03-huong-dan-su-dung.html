Cách chạy, viết bài, thêm ảnh bìa và xử lý sự cố với giao diện mới.

1. Chạy trên máy

npm install      # lần đầu
npm run dev      # http://localhost:3000
LệnhCông dụng
npm run devChạy chế độ phát triển (Turbopack)
npm testChạy bộ test
npm run lintKiểm tra lint
npm run build / npm startBuild và chạy bản production (build cũng tạo chỉ mục tìm kiếm)
Mỗi lần chỉ nên chạy một dev server ở port 3000. Nếu port đang bận, hãy dừng tiến trình cũ thay vì mở cổng khác.

2. Cách trang Bài viết hiển thị bài

Trang chủ (/) là phần giới thiệu “Về tôi”; nội dung sửa trong src/data/about-data.ts. Danh sách bài nằm ở menu Bài viết (/blog).

  • Mỗi tag một thẻ #tag. Bài có nhiều tag sẽ hiện ở khối của từng tag.
  • Mỗi thẻ mặc định hiện bài mới nhất (tiêu đề, tóm tắt ngắn, ngày, ảnh bìa). Bấm Xem thêm để thấy đủ tóm tắt và tối đa 5 bài tiếp theo ở “Bài cùng chủ đề”; Thu gọn để quay lại.
  • Khối nhiều bài hơn đứng trước. Bài không có tag vào khối “Khác”.
  • Bấm tiêu đề #tag để xem mọi bài có tag đó ở /blog.

3. Thêm bài bằng file MDX

Tạo file src/content/blog/ten-bai.mdx (tên file gồm chữ thường, số và dấu gạch ngang).

---
title: "Tiêu đề bài viết"
date: "2026-11-03"
tags: ["AI", "SAP"]          # mỗi tag là một khối chủ đề
excerpt: "Mô tả ngắn hiển thị ở thẻ bài."
coverImage: "/uploads/anh-bia.webp"   # tùy chọn
draft: false                  # true = ẩn ở bản production
---

Nội dung bài viết…
TrườngBắt buộcGhi chú
titleCó
dateCóDạng YYYY-MM-DD; dùng để sắp xếp
tagsCóMảng chuỗi; bài hiện ở khối của từng tag
excerptCóHiển thị ở thẻ bài

File thiếu trường bắt buộc sẽ bị bỏ qua và có cảnh báo trong console.

4. Thêm bài bằng trang quản trị

  1. Mở /admin, nhập mật khẩu quản trị.
  2. Tab Bài viết, tạo mới. Điền tiêu đề, slug, tags (cách nhau bằng dấu phẩy; bài hiện ở khối của từng tag), tóm tắt, nội dung.
  3. Ảnh bìa: bấm nút Tải lên để chọn ảnh từ máy; hệ thống tự điền đường dẫn dạng /uploads/….
  4. Bấm lưu. Chọn “Lưu dưới dạng nháp” nếu chưa muốn công khai.
Đừng dán URL ngoài (https://…) vào ô Ảnh bìa dù ô này gợi ý như vậy. Chính sách bảo mật của site chỉ cho ảnh cùng domain, nên ảnh sẽ không hiện và thẻ bài dùng nền gradient thay thế. Hãy dùng nút Tải lên.

Tìm kiếm và lọc danh sách bài

Phía trên danh sách có ô Tìm bài viết (tìm trong tiêu đề, slug, tóm tắt; gõ không dấu vẫn tìm được, nhiều từ thì bài phải chứa tất cả các từ), và ba ô lọc: tag, trạng thái (Đã xuất bản / Nháp), nguồn (MDX / CMS). Các bộ lọc kết hợp với nhau; dòng “3/22 bài” cho biết số kết quả và nút Xóa bộ lọc đặt lại tất cả. Mỗi dòng có ảnh bìa thu nhỏ.

Sửa bài MDX từ trang quản trị

Danh sách Bài viết trong admin hiện cả bài MDX (nhãn MDX) lẫn bài CMS (nhãn CMS). Bấm Sửa trên một bài MDX để mở form điền sẵn nội dung. Khi lưu, hệ thống tạo một bản CMS thay thế bài trên trang web; file MDX gốc không bị sửa. Slug bị khóa vì phải trùng với file để thay thế nó.

  • Nhãn CMS · thay bài MDX nghĩa là bài đang dùng bản đã sửa.
  • Bấm Khôi phục bản MDX để xóa bản CMS và dùng lại file gốc.
  • Bài MDX chưa sửa không có nút Xóa vì nó là file; muốn xóa hẳn thì xóa file trong src/content/blog/.
  • Trên bản deploy (Docker), file MDX nằm trong image nên chỉ đổi được khi build lại; bản CMS lưu trong cơ sở dữ liệu nên sửa được ngay.

Ảnh bìa và thư viện ảnh

  • Ô Ảnh bìa trong form có xem trước tỉ lệ 16:9 đúng như người đọc sẽ thấy. Bạn có thể Tải lên ảnh mới, Chọn từ thư viện hoặc Bỏ ảnh. Dán URL ngoài (https://…) sẽ có cảnh báo vì ảnh đó không hiển thị.
  • Tab Thư viện ảnh có hai nhóm: Ảnh đã tải lên và Ảnh minh họa có sẵn (20 ảnh bìa hoạt hình, chỉ để chọn, không xóa được). Có ô tìm theo tên và tải nhiều ảnh cùng lúc (mỗi ảnh tối đa 5 MB; JPEG, PNG, WebP, GIF).
  • Mỗi ảnh có nhãn Dùng ở N bài hoặc Chưa dùng. Trước khi xóa một ảnh đang dùng, hệ thống liệt kê các bài sẽ bị ảnh hỏng để bạn xác nhận.

Ngoài ra có các tab Thư viện ảnh (quản lý ảnh đã tải), Tags và Đổi mật khẩu.

Bản quyềnẢnh của bạn, nguồn miễn phí (Unsplash, Pexels) hoặc ảnh tạo bằng AI; không lấy ảnh từ trang khác

Chưa có ảnh thì cứ để trống. Thẻ bài tự dùng nền gradient kèm tên chủ đề, và khi bạn thêm ảnh sau đó thì bố cục không bị lệch.

7. Tùy chỉnh nhanh

  • Độ rộng trang: sửa .site-container trong src/styles/globals.css (hiện 960px).
  • Màu sắc: sửa các biến --color-* ở đầu globals.css (có bản sáng và tối).
  • Menu: sửa navLinks trong src/lib/site-config.ts.
  • Số bài ở “Bài cùng chủ đề”: tham số relatedLimit của groupPostsByTopic() (mặc định 5).
